# AI 교육 탐색 및 학교장의 전략적 리더십 — 퀴즈

『AI 디지털 대전환 시대, 미래인재 양성을 위한 AI 교육 탐색 및 학교장의 전략적 리더십』
(OECD Digital Education Outlook 2026 기반) PDF 강의자료에서 핵심 내용을 발췌하여 만든
10문항 4지선다 퀴즈 웹앱입니다.

## 기능
- 한 문제씩 풀고 정답 확인 + 해설을 본 뒤 다음 문제로 이동
- 진행도 표시
- 최종 결과 페이지: 점수·맞힘·틀림 통계 + 문항별 결과
- **틀린 문제만 다시 풀기** / **전체 다시 풀기** 지원
